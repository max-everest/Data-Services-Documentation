# Repository Context

This repository contains operational documentation for the Data Platform including runbooks, SOPs, data contracts, and supporting documentation.

Documentation is maintained using a **docs-as-code workflow** and published as a documentation site using **MkDocs**.

AI agents are used to assist with documentation generation. All AI-generated content must follow the repository structure and publishing workflow defined in this document.


--------------------------------------------------


# Repository Purpose

The repository serves four primary purposes:

1. Provide operational documentation for the Data Platform
2. Maintain structured runbooks and SOPs for operational teams
3. Define data contracts and platform standards
4. Support AI-assisted documentation generation

Documentation in this repository must be:

- structured
- version controlled
- reviewable
- safe for AI-assisted authoring


--------------------------------------------------


# Documentation Lifecycle

Documentation follows a controlled lifecycle.

Draft → Review → Published Documentation

AI agents generate documentation drafts which are reviewed before being promoted to the published documentation.

Only documentation located inside the `docs/` directory is published to the documentation site.

# Key Repository Areas


## Agents

Location:

.github/agents/

This folder contains AI agents used to assist with documentation generation.

Example agents:

runbook-author.agent.md
sop-author.agent.md
data-contract-author.agent.md

Agents must follow the repository rules defined in this document.


--------------------------------------------------


## Authoring Content

Location:

content/

This directory contains the **source documentation content** used for authoring.

Agents should write documentation drafts into this area.

Subfolders include:

content/blog
content/runbooks
content/sops
content/data-contracts


--------------------------------------------------


## Draft Content

Location:

content/runbooks/drafts/

Runbook drafts generated by AI agents must be written to this directory.

Example:

content/runbooks/drafts/lakehouse-refresh-failure.md

Draft documentation is reviewed before being promoted into the published content structure.


--------------------------------------------------


## Runbook Categories

Approved runbook categories include:

content/runbooks/data-platform
content/runbooks/fabric
content/runbooks/integrations

Once a draft is approved it should be moved from:

content/runbooks/drafts/

to the appropriate category folder.


--------------------------------------------------


# Published Documentation

Location:

docs/

The docs directory contains documentation that is published by MkDocs.

Content inside this directory is included in the generated documentation site.


--------------------------------------------------


## Documentation Structure

Location:

docs/runbooks
docs/sops
docs/data-contracts

These folders contain the documentation that appears on the published documentation site.


--------------------------------------------------


# Build Output

Location:

site/

The site directory contains the generated static website created by MkDocs.

This directory is generated automatically during the documentation build process.

Agents must never modify files inside the site directory.


--------------------------------------------------


# Documentation Templates

Templates are stored in:

.github/agents/

Example:

runbook-template.md

Templates define the required structure for documentation types.

Agents must use the appropriate template when generating documentation.


--------------------------------------------------


# Content Promotion Rules

Agents must follow these rules:

1. Draft documentation must be created inside:

   content/runbooks/drafts/

2. Agents must never write directly into:

   docs/
   site/

3. Documentation must follow the defined template structure.

4. Drafts must be reviewed before being promoted to the final location.


--------------------------------------------------


# Safety Rules for AI Agents

AI agents must follow these constraints:

Never modify the following directories:

docs/
site/

Always create new runbooks in:

content/runbooks/drafts/

Only move documentation into category folders after user confirmation.

Agents must not overwrite existing documentation without explicit user instruction.
